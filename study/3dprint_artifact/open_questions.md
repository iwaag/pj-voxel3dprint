## 利用者(このリポジトリの担当者)に頼むこと

- [ ] **Sketchfab の API トークン**: 半透明枠の候補(玉璧 `d763ec3d…`、雪花石膏の喪服像 `0d89139b…`、
  ヒスイ製勾玉 `0f9fe38a…`)を落とすのに必要。Sketchfab にログインし、Settings → Password & API で表示されるトークンを使う
  (`Authorization: Token <token>` で `/v3/models/{uid}/download` を呼ぶ)。トークンは `.local/` の外に書かない。
- [ ] (任意)**api.data.gov の API キー**: Smithsonian Open Access API で、候補ごとの CC0 表示(`metadata_usage`)と実寸を引くため。DEMO_KEY は上限が低い。

## プリンタのオペレータに聞くこと

材料と装填:

- [ ] 7 つのモデル材スロットに、今なにが入っているか。**VeroVivid(CyanV / MagentaV / YellowV)か、旧 Vero カラー(VeroCyan など)か**。
  白は VeroUltraWhite か VeroPureWhite か。黒は VeroUltraBlack か VeroBlackPlus か。7 本目のスロットは何か。
- [ ] 可溶性サポート(SUP706B)は使えるか。それともウォータージェットのみ(SUP705)か。
- [ ] 樹脂の入れ替えにかかる手間(フラッシングで捨てる量と時間)。美術品のために専用の構成を組むのは現実的か。

モードと仕上げ:

- [ ] 普段のモード(High Quality 14 µm / High Mix 27 µm)と、Voxel Print で使えるモード。
- [ ] 光沢(Glossy)と艶消し(Matte)を部品ごとに選べるか。艶消しで色の見え方がどれほど変わるか(実物の見本はあるか)。
- [ ] Voxel Print Utility で、画像サイズやスライス数に上限があったか(batch1 の fur は 1,418 × 354 px × 358 枚)。
  数千枚の PNG(候補 A を 60 mm にすると 2,340 枚、100 mm にすると 3,899 枚)の取り込みに、実用的な時間で耐えるか。
- [ ] GrabCAD Print の通常フルカラー(テクスチャ付きの OBJ / 3MF)で刷った経験はあるか。色が何 mm の深さまで付くか分かるか。

時間と費用:

- [ ] 60 mm 程度の器(候補 A)を High Quality で 1 個刷る場合の、造形時間とトレイの占有時間。GrabCAD Print の見積もり画面の値。
- [ ] 樹脂の社内単価(g あたり)と、サポート材の消費の目安。1 部品あたりの概算費用。
- [ ] 後処理(サポート除去、洗浄、乾燥)にかかる時間と、細部(器の注ぎ口や取っ手)が壊れやすいか。

測色:

- [ ] 社内に分光測色計(X-Rite i1 など)か、色見本を撮影できる環境(色票、定常光源)はあるか。v3 ライブラリの校正に使いたい。

## データとライセンス(調査の側で解くもの)

- [ ] Smithsonian 3D の候補 A、B について、オブジェクトページで CC0 の表示を確認する
  (当日は `3d.si.edu` が 403、Open Access API も DEMO_KEY の上限に達していた)。
- [ ] The Met の 2026 年の 3D 公開(約 140 点、CC0 との報道)の実際の配布条件。公式ページは当日 429 で読めなかった。
- [ ] GLB の単位の揺れ(m と mm が混在)。Smithsonian のメタデータに実寸があるか。
- [ ] 社内の研究開発での NC ライセンス(大英博物館など)の扱い。社外展示や販売をする場合の、法務の確認の手順。
- [ ] 人骨、宗教上の神聖物、先住民の文化財を候補から外す運用ルール(→ [license_notes.md](license_notes.md))。

## 技術(次フェーズで解くもの)

- [ ] 半透明素材(翡翠、雪花石膏)の配合を、KM サロゲートと Mitsuba だけで決められるか。クーポン(配合 × 厚さ)の実測がどの程度要るか。
- [ ] 色シェルの厚さ(0.5 mm、1 mm、2 mm)と、下地(白 / クリア)の組み合わせで、見え方がどう変わるか。
- [ ] 縮小したとき、器の壁の厚さ(実寸で数 mm)が、プリンタの最小壁厚(未確認)を下回らないか。
