# batch1 成果物の見方(日本語ガイド)

このフォルダは、J850 で実際に印刷した3部品(agate / amber / fur)の写真と、
それをレンダで再現しようとした Phase 1〜2 の成果物置き場です。
作業の経緯と数値の根拠は `.devdocs/episodes/viewer_feedback_improve/p1,p2/report*.md` に、
このフォルダには写真・表・最終図があります。

**git 管理しているもの(このフォルダ)**: 実物写真、再現に必要な設定
(`*.session.json`、`stages/*.stage.json`、formation / voxels json、領域定義と測定値の `regions-*.json`)、
知見をまとめた md、人に見せる最終図と結論の根拠図。

**git 管理していないもの(`.local/real_print/batch1/` にだけある)**: 各ステップの途中レンダ、
`diff-*.png`、`overlay/`、`*.raw.png`、古い contact sheet、`*.material_id.npy` など、
スクリプトから再生成できる中間生成物。以下の説明で **(.local)** と付けたファイルがそれです。
再生成の手順は各 report の「Commands」、元ボリュームは `work/compare/rebuild_batch1_sources.sh` にあります。

## 1. `contact-sheet-v3-final.png` — 最終コンタクトシート

**構成**: 1行 = 写真1枚。全9行(部品3 × 写真3枚)。列は左から

1. **photo** — 実物の写真(スマホ、手持ち)
2. **matched render** — 写真の4隅からカメラ姿勢を解き、**同じ視点**で描いたレンダ(v3 ライブラリ、ドーム照明ステージ)
3. **ΔL** — 明度の差(写真 − レンダ)。**赤 = 写真の方が明るい、青 = レンダの方が明るい**。±20 L でフルスケール
4. **Δb** — 黄青軸の差。**赤 = 写真の方が黄色い、青 = レンダの方が黄色い**

行の左上にその写真全体の平均 ΔE が書いてあります。

**見方のコツ**

- 差分マップが**部品全体で一様に赤か青**なら、それは写真ごとの露出の違いです(部品の差ではない)。agate の3枚で ΔL が −13 / +7 / +3 と符号が変わるのはこのためです。撮影条件を固定すれば消えます(Phase 3 の撮影プロトコルの根拠)。
- 差分マップに**模様に沿った構造**が見えれば、それがレンダ側の色の誤差です。agate の細い暗い帯が赤く出る(写真の方が明るい)、あるいは帯の縁が赤青の縞になる(0.3 mm 程度の位置ずれ)など。
- amber と fur の行は、写真とレンダをぱっと見で区別しにくいところまで来ています。agate は色相と帯位置は合い、明度に差が残ります。

**同じ形式の途中経過** (.local): `renders-p2/step3/contact-sheet-v3-v2.png`(v2 ライブラリ)と
`renders-p2/step4b/contact-sheet-v3-v3b.png`(= 最終と同じ)。2枚を並べると、
フィットで何が変わったか分かります。

## 2. `contact-sheet-v3-final.md` — 領域ごとの数値表

各行が「領域」(agate の帯の色ごと、amber のホスト材料ごと、fur の下毛・毛束・透明縁など、計21)。
列は

- **photos L a b (spread)** — 写真3枚の平均 Lab と、3枚のばらつき(ΔE)。**spread が大きい領域は写真自体が不安定**なので、レンダとの差がその値以下なら「これ以上は写真では判定できない」と読みます
- **regions-v3-v2 / v3a / v3b** — 各ライブラリのレンダの Lab と、写真平均との ΔE

**見方**: ΔE が spread より小さければ「一致した(写真限界内)」、大きければ「レンダ側に残差あり」。
最終行の sum は全領域の合計 ΔE で、v2 → v3 で 174 → 114 になりました。21領域中19が spread 内です。

Lab の読み方: L は明度(0 黒〜100 白)、a は緑(−)〜赤(+)、b は青(−)〜黄(+)。ΔE は色差で、
おおよそ 2〜3 で「並べて分かる」、10 を超えると「明らかに違う」程度の感覚です。
ただしスマホ写真の正規化を経ているので、ここでの ΔE は相対的な目安です。

## 8. 差分画像(`diff-*.png`, .local)の読み方

6連の画像です。

1. photo — 写真
2. render — 同じ視点のレンダ
3. photo warped to render — 写真をレンダの視点に幾何変換したもの(重ね合わせ用)。周辺の暗い帯は変換で情報が無い部分
4. ΔL — 明度差。赤 = 写真が明るい
5. Δa — 赤緑差。赤 = 写真が赤い
6. Δb — 黄青差。赤 = 写真が黄色い

すべて ±20 でフルスケール、白は差なし。**部品全体が一様に色づいていれば露出差、模様に沿って色づいていれば材料の誤差**、と読み分けてください。

## 9. 今の到達点と限界(短く)

- amber と fur は写真と見分けがつきにくい水準。agate は色相と帯位置は一致、明度に +6〜8 L の差(暗い帯)が残る
- 残差の最大要因は写真の露出ばらつき(同じ部品で ±15〜20 %)。次に、magenta と yellow の係数が推定範囲の端に張り付いている問題。どちらも模様の写真からは解けない
- 印刷物は設計の鏡像で出ている(batch1 では実害なし)
- これらは Phase 3(クーポン印刷と撮影プロトコル)で扱う。手順は `.devdocs/episodes/viewer_feedback_improve/p3/manual.md`
